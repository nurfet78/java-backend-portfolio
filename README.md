### Conference Room Booking System

Сервис бронирования переговорных комнат.

**Что реализовано**

- защита от конкурентного бронирования
- pessimistic locking
- транзакции
- Flyway
- Testcontainers
- REST API
- Docker

**Стек:** Java 21 • Spring Boot • PostgreSQL • Docker • Testcontainers • Flyway

🔗 **Репозиторий:** [conference-room-booking-system](https://github.com/nurfet78/conference-room-booking-system)

### Spring Security & JWT

Проект демонстрирует современную JWT-аутентификацию.

**Что реализовано**

- Access Token
- Refresh Token
- роли USER / ADMIN
- отзыв refresh token
- кастомные ошибки авторизации

**Стек:** Java 21 • Spring Security • JWT • PostgreSQL

🔗 **Репозиторий:** [SpringSecurity](https://github.com/nurfet78/SpringSecurity)

### Event Management System

REST-сервис управления мероприятиями.

**Что реализовано**

- мероприятия
- помещения
- участники
- email-уведомления
- Swagger

**Стек:** Java • Spring Boot • PostgreSQL • REST API

🔗 **Репозиторий:** [EventManagementSystem](https://github.com/nurfet78/EventManagementSystem)

### ATM Emulator

Эмулятор банкомата с поддержкой конкурентной обработки операций.

**Что реализовано**

- многопоточность
- rollback при ошибках
- отказоустойчивая выдача средств
- покрытие JUnit 5

**Стек:** Java 21 • JUnit 5

🔗 **Репозиторий:** [ATMEmulator](https://github.com/nurfet78/ATMEmulator)
